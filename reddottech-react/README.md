# RedDot Technologies Platform

Official web application for RedDot Technologies, featuring professional ICT certification training, PECP bootcamps, and the free AI Unlocked Academy.

## Technology Stack

- **Framework**: TanStack Start (React 19 + Vite 8)
- **Styling**: Tailwind CSS v4 + Vanilla CSS
- **Router**: TanStack Router

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```
